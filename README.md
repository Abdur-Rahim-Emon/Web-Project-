# Web-Project-
Transport Automation
## Transport Automation System

This project is a web-based Transport Automation System developed as a student project.
It manages transport operations such as admin control, driver management, and payment handling.how admin can 
control the whole system and input data to the database .Besides notify the driver assigned schedule .
For the passenger gps tracking has been included .(payment is on sandbox feel free to use).
The login has been using password hashing.
## Features
- Admin dashboard
- Driver management
- Payment module
- Backend API integration
- Database connectivity

## How to Run the Project
1. Install XAMPP
2. Start Apache and MySQL
3. Import the database from the `Database` folder
4. Place the project inside `htdocs`
5. Open browser and visit:
   http://localhost/Web-Project-
